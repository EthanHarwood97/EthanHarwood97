# Ethan Harwood

I'm a developer in Blackburn, UK. I run [KinKo Digital](https://kinkodigital.com), where we build the internal tools and business automations that keep leads moving, jobs on track, stock visible and invoices paid.

Most of that work stays private. The way I build is public: small Python and TypeScript projects that run themselves on free infrastructure and do one job properly.

## Public projects

- **[coding-model-value-leaderboard](https://github.com/EthanHarwood97/coding-model-value-leaderboard)** — ranks LLMs for coding agents by quality-per-dollar, blending SWE-bench Pro, Aider Polyglot and LiveCodeBench into one score. Updated weekly.
- **[ai-model-tracker](https://github.com/EthanHarwood97/ai-model-tracker)** — polls public AI leaderboards every 30 minutes and turns them into recommendations by role: general coder, UI coder, complex code. Self-hosted, runs for free on GitHub Actions.
- **[acres-per-pound](https://github.com/EthanHarwood97/acres-per-pound)** — scrapes Rightmove UK-wide and ranks every listing by pounds per acre, from bare plots to houses with land.
- **[holiday-tracker](https://github.com/EthanHarwood97/holiday-tracker)** — watches accommodation and flight prices across Booking.com, Airbnb and Expedia, and flags drops of more than 20% against the recent average.
